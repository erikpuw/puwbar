# PuwBar v1.0.1

## Tiếng Việt

Phiên bản `v1.0.1` chuyển PuwBar sang cơ chế tùy biến trực tiếp cây XAML của thanh taskbar gốc Windows 11 qua `InitializeXamlDiagnosticsEx`, đóng gói gọn trong một file `puwbar.exe` duy nhất (khoảng 1,2 MB RAM khi chạy nền).

### Có gì mới
- **Tùy biến trực tiếp taskbar gốc:** Nhúng sẵn `puwbar_tap.dll` vào `puwbar.exe`. Giữ nguyên 100% tính năng gốc của Windows 11: icon tray có animation (RunCat 365, UniKey), menu chuột phải gốc, lưới icon `^` và Start menu.
- **Kính mờ GPU thời gian thực:** Dùng `CreateBackdropBrush()` + `D2D1GaussianBlur` (`OPTIMIZATION_SPEED`), lớp kính khói 24%, viền trắng mảnh 15%, bo góc 12px và padding sát mép 3px.
- **Hỗ trợ đủ 4 cạnh màn hình & căn lề Left/Center:** Tự động xoay bố cục theo thời gian thực khi đổi vị trí **Bottom / Top / Left / Right** hoặc căn lề **Left / Center** trong Windows Settings.
- **Bọc kính đồng bộ cho Widgets và popup overflow:** Tự bọc kính nút Widgets khi người dùng bật trong Windows, đồng thời bọc kính popup `^` và `...`.
- **Sửa lỗi vạch đánh dấu cạnh phải:** Khóa đúng vạch đánh dấu ứng dụng đang chạy về cạnh phải khi đặt thanh dọc bên phải màn hình.
- **Icon ứng dụng, menu System Tray & đa ngôn ngữ:** Nhúng icon riêng vào `puwbar.exe`, thêm menu chuột phải ở tray gồm chọn ngôn ngữ (**Tiếng Việt / English**), hộp thoại **Giới thiệu (About)**, **Áp dụng lại giao diện**, **Khởi động cùng Windows** (Task Scheduler chạy ngay lúc đăng nhập, không trễ, có tự thử lại 30 giây chờ Explorer XAML sẵn sàng) và **Thoát PuwBar** (`Ctrl+Alt+F12`).

### Kiểm tra
- 17 unit test và `cargo clippy --all-targets -- -D warnings` đều qua.
- Đã kiểm thử thực tế trên Windows 11 Pro Build 26300 (1920×1080 @ 144Hz), xác nhận khôi phục đầy đủ thuộc tính XAML khi thoát.

## English

`v1.0.1` moves PuwBar to native Windows 11 XAML taskbar styling via `InitializeXamlDiagnosticsEx`, packaged as a single standalone `puwbar.exe` (~1.2 MB idle RAM).

### What's new
- **Native taskbar styling:** Embeds `puwbar_tap.dll` inside `puwbar.exe` and preserves all native Windows 11 taskbar and System Tray behavior, including live animated tray icons (RunCat 365, UniKey), right-click menus, and the native overflow grid.
- **Real-time GPU frosted glass:** Uses `CreateBackdropBrush()` with speed-optimized `D2D1GaussianBlur`, 24% dark-smoke tint, 15% white hairline border, 12px corner radius, and tight 3px side padding.
- **All 4 taskbar edges & Left/Center alignment:** Tracks Windows Settings changes for **Bottom / Top / Left / Right** and **Left / Center** alignment in real time.
- **Matching glass for Widgets and overflow flyouts:** Automatically styles the Widgets pill when enabled in Windows along with the `^` and `...` overflow flyouts.
- **Right-edge indicator fix:** Locks the active-app indicator to the right edge when the taskbar is docked vertically on the right.
- **App icon, System Tray menu & VI/EN localization:** Embedded multi-size `.ico`, System Tray menu with **Vietnamese / English** language toggle, **About** dialog, **Reapply**, **Start with Windows** (immediate-logon Task Scheduler task with 30s Explorer readiness retry), and **Exit** (`Ctrl+Alt+F12`).

### Verification
- 17 unit tests and `cargo clippy --all-targets -- -D warnings` pass.
- Verified on Windows 11 Pro Build 26300 (1920×1080 @ 144Hz) with clean XAML restoration on exit.
